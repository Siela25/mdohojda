# mdohojda.dev — Portfolio

Personal portfolio website and CV for Mateusz Dohojda, a backend developer from Gdynia, Poland.

Built with a terminal-inspired aesthetic: monospace font, dark theme, minimal styling.

## Stack

- [Next.js 16](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS 4
- shadcn/ui

## Pages

- `/` — Portfolio (About, Skills, Employment, Projects, Contact)
- `/resume` — CV with PDF export via browser print

## Running locally

```bash
bun dev
```

Open [http://localhost:3000](http://localhost:3000).
